## Project Overview
This repository contains the custom source code for the official Ubuntu Addiction Recovery website. The site serves as the central online presence for the organisation, communicating hope, dignity, connection, and practical action. 

## Core Brand Message
**Ubuntu — I am because we are.**

## Brand Identity & Colours
*   **Grape Purple:** Restoration, dignity, and depth.
*   **Gold:** Hope, value, and transformation.
*   **Orange:** Warmth, energy, and renewal.
*   **Teal:** Balance, calm, and wellbeing.
*   **White:** Clarity, openness, and readability.
*   **Silver/Light Grey:** Supporting backgrounds and subtle details.

## Technology Stack
*   **HTML5:** For the structure and content of the pages.
*   **CSS3:** For styling, layout, and applying the official brand palette.
*   **JavaScript:** For interactive elements (like the mobile menu).
*   **GitHub Pages:** For free, secure, and fast hosting.

## Website Structure
*   `index.html` (Home page)
*   `about.html` (About Us)
*   `app.html` (The App)
*   `bookshop.html` (Bookshop)
*   `youtube.html` (YouTube)
*   `podcast.html` (Podcast)
*   `contact.html` (Contact)
*   `style.css` (The master design file)
*   `images/` (Folder for logos and photos)
